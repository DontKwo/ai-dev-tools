# Security Policy

## Supported Versions & Official Releases

| Version / Branch | Supported | Notes |
| :--- | :--- | :--- |
| `main` (Latest `vX.Y.Z` Release) | Yes | Actively maintained official release stream |
| Forks, Mirrors, and Older Tags | No | Unverified and unsupported |

Official binaries and installers are distributed exclusively from the primary `DontKwo/<Repo>` repository on GitHub (`main` branch and official [Releases](https://github.com/DontKwo/<Repo>/releases/latest)).

- **Fork Safety Warning**: Do **not** download or run installers, executables, or APKs from forked repositories or third-party mirrors unless you have verified the source code yourself and confirmed they contain no malware. Only `DontKwo/<Repo>` `main` builds are maintained by the author.
- **OS & Mobile Security Prompts**: Because `<AppName>` is published independently without paid commercial code-signing certificates or Play Store review, Windows SmartScreen, macOS Gatekeeper, and Android Play Protect may warn that the download is unrecognized or potentially unsafe. Review [Desktop Installation Guide](docs/INSTALLATION.md) (or [Android APK Installation Guide](docs/APK_INSTALLATION.md) where applicable) and bypass security prompts strictly at your own discretion.

## Reporting a Vulnerability

If you discover a security issue in `DontKwo/<Repo>`:

1. **Do not** disclose exploit details or credentials in a public GitHub Issue.
2. Open a [Private Vulnerability Report](https://github.com/DontKwo/<Repo>/security/advisories/new) on GitHub (or contact `@DontKwo` via GitHub profile if private advisories are unavailable).
3. Include reproduction steps, affected operating system or version, and any suggested fix.
